# Execution controls: FUI-029 integration

## Scope

The existing chat now includes explicit tool opt-in, a persisted conversation mode,
ordered recent execution events, pending authorization, resource ownership, explicit
interruption of another conversation, and retained-writer warnings. Regular chat
remains the default. Changing mode does not dispatch approvals or cancel a run.
Copy is provided in Portuguese, English and Spanish.

Cancellation targets an exact conversation/run pair. The backend checks ownership
and observes persisted cancellation while the cycle is in flight. Unconfirmed
writers remain locked. Failed or cancelled replies cannot copy an earlier run's
answer or be marked completed.

## Verification

- `pnpm build` passes, including TypeScript checking.
- `pnpm exec playwright test --config=playwright.execution.config.ts`: six tests pass.
- `cargo test`: 364 library tests, 17 agent-cycle tests, and all other integration suites pass; eight existing live-environment tests remain ignored.
- `cargo clippy --lib -- -D warnings` remains blocked by the pre-existing nested conditional in `chat.rs:888`; no new lint was reported.
- The Impeccable detector reports no findings on the changed UI targets.

The browser tests intercept static build assets and mock IPC entirely within
Playwright. They do not start a development/preview server, contact a real model,
or exercise native macOS confirmation dialogs. They cover mode changes without
implicit decisions, reconstruction after reload, targeted cancellation, another
conversation's cancellation failure, retained locks, tool opt-in, and ordinary
chat with an incompatible model.

## Captures

All data is synthetic. Screenshots are generated by the browser tests and were
inspected at 1440 and 960 pixels. The controls wrap within the existing chat
surface; interruption failure stays in the confirmation dialog. Existing repeated
empty-message placeholders visible elsewhere in the working-tree chat are outside
this change and have not been edited.

## Remaining limitations

- Approval suspension is observable and cancellable, but resuming the model cycle
  after a later approval is not implemented. The interface states this explicitly.
- Process commands and actual file writes remain capability-gated. No process-tree
  termination or file recovery is claimed by this interface.
- Event history is a bounded projection of up to 100 persisted state/result rows.
  Reconnection reads state; it never replays effects.
- Native end-to-end testing against a real loaded model is still required before
  claiming the entire FUI-029 acceptance surface is complete.
